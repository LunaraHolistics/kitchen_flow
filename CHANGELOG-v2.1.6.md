# Kitchen Flow v2.1.6 - Novidades

## ✨ Novas Funcionalidades
- 🔑 PIN diário automático para acesso dos garçons
- 📱 Página mobile para garçons com notificações em tempo real
- 🎯 Destaque visual para pedidos Kids/Porções no tablet da cozinha
- 💾 Cache offline de 30 minutos (funciona sem internet)
- 📲 Instalação como App (PWA) com ícone personalizado

## 🔒 Segurança
- PIN não repete nos últimos 7 dias
- Acesso restrito à rede local (configurável no roteador)
- Mascaramento de PIN na interface para privacidade

## 🐛 Correções
- Tratamento robusto para bloqueio de antivírus
- Filtro de delivery não exibe pedidos na cozinha
- Observações em destaque para evitar esquecimentos

## 📋 Requisitos
- Windows 10/11 no PC do caixa
- Navegador moderno no tablet/celular (Chrome, Safari, Edge)
- Rede Wi-Fi local para comunicação entre dispositivos

## 🔄 Atualização
1. Fechar Kitchen Flow Bridge atual
2. Substituir pasta pelos novos arquivos
3. Reiniciar Bridge e definir PIN do dia
4. Garçons: acessar nova URL e instalar como app
